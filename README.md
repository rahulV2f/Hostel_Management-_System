Hostel Management System

A web-based hostel management application designed to simplify hostel administration and improve the management of student accommodation.

🚀 Project Overview

This project aims to provide a simple and user-friendly interface for managing hostel-related activities, including room allocation, student information, and complaint management.

Project Status:Frontend Development

✨ Planned Features

- Student information management
- Hostel room allocation
- Room and accommodation details
- Complaint management
- Complaint categories:
  - Electrical
  - Plumbing
  - Drinking Water
  - Carpentry
  - LAN

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
